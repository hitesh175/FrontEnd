## Run locally

Serve the repository root:

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in a browser and select a page. Most static examples can also be opened directly, but AJAX examples may require an HTTP server and their referenced resources.

## Scope

These are independent learning exercises, with no shared application build. Keep the portfolio's assets alongside its HTML file. Preserve third-party attribution and licence notices when reusing bundled templates, fonts, or libraries.
